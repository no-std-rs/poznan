# Development

The library and its runtime dependencies must compile without `std` or `alloc`.
Keep variable storage caller-owned and report capacity overflow. Networking,
TLS, subprocesses and hosted output belong in examples or separate adapters.

Source: the waste lookup and schedule HTML at poznan.pl. Preserve exact building
groups and object IDs, including trailing punctuation. Several objects can share
one street number and have different schedules. Unknown layout or waste fraction
codes must fail visibly. Never treat a missing schedule as an empty calendar.

All events remain provisional until parsing and transport both finish
successfully. Do not publish partially fetched or parsed updates.

Run the README validation commands. Offline fixtures are synthetic; tests must
not depend on live city services. The allocation probe runs as a standalone
executable without the concurrent libtest harness. Report ABI
storage sizes separately from complete device or HTTP/TLS RAM measurements.

Use Conventional Commit titles. Runnerless evaluates Codex review from the
trusted base revision; see docs/runnerless.md for enrollment and enforcement.
